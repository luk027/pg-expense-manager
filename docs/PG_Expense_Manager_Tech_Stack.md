# PG Expense Manager --- Technology Stack

This document lists the technologies selected for the PG Expense Manager
project.

## Frontend

  Area                   Technology
  ---------------------- -----------------------------
  Framework              React Native
  Development platform   Expo
  Language               TypeScript
  Web support            React Native Web / Expo Web

## Backend

  Area               Technology
  ------------------ --------------------
  Runtime            Node.js
  Language           TypeScript
  API framework      Hono
  API hosting        Cloudflare Workers
  Input validation   Zod
  Authentication     Better Auth

## Database

  Area                               Technology
  ---------------------------------- -----------------------
  Database                           Neon
  Database engine                    PostgreSQL
  ORM                                Drizzle ORM
  Workers-to-database connectivity   Cloudflare Hyperdrive

## Hosting and Infrastructure

  Area               Technology
  ------------------ --------------------
  Frontend hosting   Cloudflare Pages
  Backend hosting    Cloudflare Workers
  Database hosting   Neon
  Source control     GitHub

## Summary

-   **Frontend:** React Native + Expo + TypeScript
-   **Backend:** Node.js + TypeScript + Hono
-   **Database:** Neon PostgreSQL
-   **Database access:** Drizzle ORM
-   **Validation:** Zod
-   **Authentication:** Better Auth
-   **Backend hosting:** Cloudflare Workers
-   **Frontend hosting:** Cloudflare Pages
-   **Database connectivity:** Cloudflare Hyperdrive
-   **Source control:** GitHub
